# Stock Item Inquiry Include Stock Assembly Releases

Public, signed binary update feed for the CHANTCH **Stock Item Inquiry Include Stock Assembly** AutoCount plug-in.

Each release holds the plug-in DLL in a zip and `latest.json`: an RSA-SHA256-signed manifest (product id, version,
package URL, package SHA-256). The installed plug-in verifies the signature against its embedded public key, and the
package hash, before installing. Source code, signing keys, credentials, customer data and licence data are never
stored here.

Official product information: [chantch.com.my](https://chantch.com.my)
